# Kickstarter Data Analysis & Visualization

This project explores crowdfunding data using exploratory data analysis (EDA) and visualization techniques to uncover patterns in funding success across categories and time.

## Objectives
- Analyze differences in pledged amounts across categories
- Understand distribution of backers and funding behavior
- Identify trends in successful vs failed projects
- Explore variability and outliers in crowdfunding data

## Methods & Visualizations
- **Boxplots**: Compared pledged amounts across categories (e.g., Publishing vs Art)
- **Violin plots**: Analyzed distribution and spread within subcategories (e.g., Dance types)
- **Histograms**: Examined distribution of backers across categories
- **Line charts**: Identified time trends in pledged amounts by project status
- **Categorical plots**: Compared frequency and composition of project types

## Key Findings
- Publishing projects tend to have higher median pledged amounts than Art
- Some categories show significant outliers, indicating high variability
- Backer distributions vary widely across categories
- Successful and failed projects exhibit different time trends
- Certain categories show higher upside potential but also greater volatility
